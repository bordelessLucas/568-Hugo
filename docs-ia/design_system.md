# Design system - RotaTrucks

A logo é a referência. Azul da marca, caminhão branco, baú laranja. Não usar amarelo de faixa nem azul-noite.

Arquivo: `design_system/logo.png`

## Cor

| Token | Hex | Uso |
|---|---|---|
| brand | #0073B8 | Fundo da marca, cabeçalho, botão secundario |
| accent | #FF9C1A | Ação principal. É o laranja do baú. |
| accentInk | #1F1404 | Texto sobre o laranja |
| fog | #F2F8FC | Fundo da tela |
| surface | #FFFFFF | Campo e painel |
| ink | #073049 | Texto |
| muted | #4E6A7C | Apoio |
| line | #C9DDE8 | Borda |
| onBrand | #FFFFFF | Texto sobre o azul |
| onBrandMuted | #D7ECF7 | Apoio sobre o azul |
| danger | #C5362B | Erro e não passa |
| pass | #1B7A45 | Passa |

O laranja é preenchimento de botão. Não usar como texto pequeno sobre branco.

## Tipo

Nunito, a mesma família da marca: aberta, em negrito, sem condensar.

| Papel | Tamanho | Peso |
|---|---|---|
| Marca | logo | - |
| Título | 36 | 800 |
| Corpo | 16 | 400 |
| Rótulo | 14 | 700 |
| Caption | 13 | 400 |

## Espaço

Escala: 4, 8, 12, 16, 24, 32, 48. Margem da tela: 20. Campo e botão: altura 52. Raio do campo: 12. Raio do botão: 14.

## Princípio

A logo entra no cabeçalho, sobre o azul #0073B8. O laranja aparece uma vez por tela, no botão principal. O resto fica claro: branco e azul bem diluído. Alinhamento à esquerda. Uma acao principal por tela.
